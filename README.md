# Rynx CLI

A zero-config CLI tool for Git and Jira integration.

## Features

- **Auth**: Manage Jira credentials.
- **Tickets**: List and filter Jira tickets directly from the terminal.
- **Init**: Initialize project-specific configurations.

## Development

### Prerequisites

- Go (1.21+)

### Building

```bash
make build
```

### Running

```bash
./bin/dev ping
```
